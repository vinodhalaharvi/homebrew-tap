# vinodhalaharvi/tap

```sh
brew install vinodhalaharvi/tap/collage
brew install vinodhalaharvi/tap/trim
brew install vinodhalaharvi/tap/tilegen
```

| Formula | What it does |
|---|---|
| [collage](https://github.com/vinodhalaharvi/collage) | Arrange photos into a gap-free collage of any shape |
| [trim](https://github.com/vinodhalaharvi/trim) | Cut a talk, podcast or video to an exact length, keeping the best parts |
| [tilegen](https://github.com/vinodhalaharvi/tilegen) | Compile a small spec into Go scaffolding, leaving precise holes for an LLM |
